# Portfolio

An interactive deep-space observatory. My projects are solar systems, the open-source record is a galaxy, and you fly a camera between them. React, TypeScript, three.js, and Tailwind underneath.

**Live site: [manoharpaturi.github.io/portfolio](https://manoharpaturi.github.io/portfolio/)**

## How this got made

One prompt. I described the site I wanted in Google AI Studio, it generated the entire app, and I pushed the export here and turned on GitHub Pages. Total effort after the prompt: `npm run build`, one workflow file, and a git push.

If you've been putting off building a portfolio because it sounds like a weekend project, it isn't anymore. Describe the thing you want well and AI Studio builds it faster than you can scaffold it yourself. used Gemini Neon by the way 

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. `npm run build` writes the static bundle to `dist/`, which is what GitHub Pages serves.
